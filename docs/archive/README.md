# 归档（archive/）

这里放**被后续轮次整体取代**的文档快照。归档 ≠ 删除：保留是为了可追溯（"当时
为什么这么判断"），但**任何归档内容都不代表当前状态**。

## 归档规则

1. **什么进来**：整篇被取代的快照——日期命名的审计/分析、"某时点的能力清单"、
   一次性选型报告。**局部的**历史数据不搬，留在原文档并标 `【历史·<轮次>】`。
2. **什么不进来**：与时点无关的根因分析（如微架构推导、语义对齐论证）——这些
   仍有效，留在 `docs/` 正文。
3. **搬进来必须做三件事**：
   - 文首加**归档块**：归档日期 + 被谁取代（指向当前状态文档与 RESULTS 小节）+
     保留理由；
   - `docs/index.md` 的「归档」分区登记一行；
   - 全仓更新引用路径（`grep` 旧文件名确认无残留）。
4. **状态归属**：当前性能 → `benchmarks/RESULTS.md` §2.9；当前进度 →
   `status.md` §2/§5.1；当前路由 → `status.md` §3。
